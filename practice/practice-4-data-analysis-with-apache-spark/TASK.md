<strong>Задание</strong>

<strong><strong>1\. Установите в виртуальной машине Ubuntu фреймворк Apache Spark</strong>.</strong>

<strong>2\. Напишите программу для анализа данных с помощью библиотеки машинного обучения Spark MLlib, которая решает задачу бинарной классификации текстовых документов методом машинного обучения логистическая регрессия. </strong>Требования к программе:

- Документы должны делиться на два класса «статья про Spark» и «другая статья». Пример датасета:

  | Содержимое документа | Класс, к которому принадлежит документ |
  | --- | --- |
  | a b c d e spark | статья про Spark |
  | b d | другая статья |
  | spark f g h | статья про Spark |
  | hadoop mapreduce | другая статья |
- Используйте ML-конвейер.
- Оцените точность модели.
- Составьте с помощью Spark SQL матрицу ошибок (Confusion Matrix) и отобразите ее в виде круговой диаграммы.
- Запустите вашу программу в кластерном режиме в Apache Spark.

<strong>3\*. Разработайте Spark-программу для классификации ирисов Фишера.</strong> Требования к программе:

- Загрузите приложенный файл с датасетом iris.csv в HDFS (во вложении, оригинал здесь: https://www.kaggle.com/datasets/saurabh00007/iriscsv?resource=download). Читайте данные для машинного обучения из HDFS.
- Обучите модель с помощью метода машинного обучения логистическая регрессия. Сделайте предсказания по обученной модели.
- Сделайте оценку точности модели.
- Постройте на основе тестовых данных точечную диаграмму, где цветом заливки точки обозначен истинный класс точки, а цветом обводки точки – предсказанный класс. Пример графика:![](%D0%9F%D0%97%203.%20%D0%B4%D0%B8%D0%B0%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B0.png)
