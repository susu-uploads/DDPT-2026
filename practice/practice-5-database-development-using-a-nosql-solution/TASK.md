<strong>Задание</strong>

<strong>1\. Установите в виртуальной машине Ubuntu в псевдораспределенном режиме NoSQL-решение HBase.</strong>

<strong>2\. Создайте таблицу писателей 'Writers' </strong>с семействами столбцов author, books, children:

| Идентификатор строки | author | books | children |
| --- | --- | --- | --- |
| 1 | author:name “Pushkin A.S.” author:age ”221” | books:book “Fairy tales” |  |
| 2 | author:name “Edgar Poe” | books:book “The Raven” |  |
| 3 | author:name “Nekrasov N.A.” | books:book “Poetry” | children:num “0” |

Выполните над таблицей следующие действия:

- Просмотр содержимого всей таблицы Writers
- Вывод на экран содержимого строки с идентификатором ‘1’ в таблице Writers
- Вывод на экран содержимого столбца ‘books:book’ в строке ‘1’ таблицы Writers
- Вывод на экран из таблицы Writers только тех строк, у которых author:name\=’Pushkin A.S.’
- Вывод на экран из таблицы Writers только тех строк, у которых author:age\>\=50
- Удаление таблицы Writers

<strong>3\*. Создайте таблицу(-ы) в HBase на основе загруженного в HDFS CSV-файла, представляющего собой свободно распространяемый датасет о розничных транзакциях: </strong><https://www.kaggle.com/datasets/prasad22/retail-transactions-dataset>.

<strong>Напишите Spark-приложение</strong> для реализации следующих запросов к базе данных:
1\) Отобразите транзакции, общая стоимость которых менее 10 у.е.
2\) Вычислите общую стоимость покупок, сделанных в помощью кредитных карт.
3\) Определите ТОП-5 покупателей, которые чаще всего делали покупки (у кого больше транзакций).
4\) Определите ТОП-5 наиболее покупаемых товаров.

<strong>Вопросы к заданию</strong>

- Что такое семейство столбцов в HBase? Как создать семейство столбцов?
- Какие операции над данными есть в языке запросов HBase?
- Зачем нужен процесс HMaster? Назовите его основные функции.
