<strong>Задание</strong>

<strong>1\. Установите платформу Hadoop</strong>. Для этого выполните следующее:

1. Установите программу для виртуализации операционных систем Oracle VM VirtualBox;
2. Создайте виртуальную машину в VirtualBox, установите операционную систему Ubuntu (дистрибутив GNU/Linux);
3. Установите и настройте в виртуальной машине Ubuntu платформу Java и сетевой протокол SSH;
4. Установите и настройте Hadoop;
5. Запустите сервисы HDFS и MapReduce на Yarn (NameNode, DataNode, ResourceManager, NodeManager, SecondaryNameNode). Запуск проверьте командой jps.

<strong>2\. Выполните </strong>следующие <strong>задания по работе с HDFS</strong>:

1. Создайте в локальной домашней директории Ubuntu файл «data.txt». Внесите туда несколько строк текста.
2. Создайте в HDFS новую папку data, cкопируйте в нее файл «data.txt».
3. Отобразите содержимое файла «data.txt» из HDFS.
4. Определите, на сколько блоков данных был разбит файл «data.txt» при сохранении в HDFS?

<strong>3\*. Выполните задания по работе с большими данными:</strong>

1. Загрузите следующий CSV-файл, представляющий собой свободно распространяемый датасет о розничных транзакциях: <https://www.kaggle.com/datasets/prasad22/retail-transactions-dataset>.
2. Скопируйте файл в HDFS, указав при этом размер блока данных, равным 64Мб.
3. Где на жестком диске сохранились блоки с данными файла? Сколько блоков было загружено в HDFS? Почему столько?
4. Отобразите последние несколько строк файла, загруженного в HDFS.
5. Какой фактор репликации имеет файл? Необязательно: измените фактор репликации на 2\.
6. Напишите sh-команду для подсчета количества строк в файле, хранящемся в файловой системе HDFS.
