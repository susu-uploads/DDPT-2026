**Задание**

**1. Установите платформу Hadoop**. Для этого выполните следующее:

- Установите программу для виртуализации операционных систем Oracle VM VirtualBox;

- Создайте виртуальную машину в VirtualBox, установите операционную систему Ubuntu (дистрибутив GNU/Linux);

- Установите и настройте в виртуальной машине Ubuntu платформу Java и сетевой протокол SSH;

- Установите и настройте Hadoop;

- Запустите сервисы HDFS и MapReduce на Yarn (NameNode, DataNode, ResourceManager, NodeManager, SecondaryNameNode). Запуск проверьте командой jps.

**2. Выполните**следующие **задания по работе с HDFS**:

- Создайте в локальной домашней директории Ubuntu файл «data.txt». Внесите туда несколько строк текста.

- Создайте в HDFS новую папку data, cкопируйте в нее файл «data.txt».

- Отобразите содержимое файла «data.txt» из HDFS.

- Определите, на сколько блоков данных был разбит файл «data.txt» при сохранении в HDFS?

**3*. Выполните задания по работе с большими данными:**

- Загрузите следующий CSV-файл, представляющий собой свободно распространяемый датасет о розничных транзакциях: [https://www.kaggle.com/datasets/prasad22/retail-transactions-dataset](https://www.kaggle.com/datasets/prasad22/retail-transactions-dataset).

- Скопируйте файл в HDFS, указав при этом размер блока данных, равным 64Мб.

- Где на жестком диске сохранились блоки с данными файла? Сколько блоков было загружено в HDFS? Почему столько?

- Отобразите последние несколько строк файла, загруженного в HDFS.

- Какой фактор репликации имеет файл? Необязательно: измените фактор репликации на 2.

- Напишите sh-команду для подсчета количества строк в файле, хранящемся в файловой системе HDFS.

**Вопросы к заданию**

- Что такое фактор репликации? Какая команда для HDFS позволяет изменить фактор репликации?
- Как определить, на сколько блоков будет разбит загруженный в HDFS файл?
- Какие команды в HDFS позволяют отобразить файл?
